# NIBT Website — Next.js Classic Academic Theme

A functional **local Next.js website** for National Institute of Business and Technology (NIBT), with the **Classic Academic** navy/gold theme selected by the client.

## Contents
- Responsive website: home, about, governance, courses, admissions/fees, support, policies, complaints information, student portal placeholder, contact.
- NIBT logo supplied by the client.
- Course structures imported from the supplied Bachelor and Master subject-selection Word documents (V2.0).
- 48 policy titles imported from the supplied Policy Register V2.0 Excel workbook. Policy PDFs are **not supplied**, so links are not fabricated.
- Functional **expression-of-interest** form (not enrolment); records are encrypted at rest with AES-256-GCM in a local `.ndjson` file.
- Complaints information page **without** a complaint form, as requested.
- Express regulatory warnings about proposed/unaccredited course status.

## Installation on Windows (target folder: `C:\NIBT`)
1. Install **Node.js 22 or newer** from https://nodejs.org/ . **Python and a `.venv` are not used** for Next.js. Dependencies are installed with npm into `node_modules`.
2. Extract the supplied ZIP so that `C:\NIBT\package.json` exists.
3. Open Windows PowerShell in `C:\NIBT`.
4. Run:

   ```powershell
   Set-ExecutionPolicy -Scope Process Bypass
   .\setup.ps1
   npm run dev
   ```

5. Open **http://localhost:3000**. Stop the development server using Ctrl+C.
6. To review encrypted local enquiries:

   ```powershell
   npm run enquiries:list
   ```

7. Before any external deployment, run `npm run build` and `npm run typecheck` once dependencies are installed.

### Manual setup, if PowerShell execution is restricted

```powershell
cd C:\NIBT
npm install
# Generate an independent 32-byte random secret in hexadecimal (64 characters),
# then create .env.local using the keys illustrated in .env.example.
npm run dev
```

## Architecture
- **Next.js 16.4.6**, App Router, React 19, TypeScript, custom CSS. Source: https://nextjs.org and https://www.npmjs.com/package/next
- Local server side endpoint: `POST /api/enquiries`.
- Local encrypted submissions file: `data/enquiries.ndjson` (private, not served from `public/`).
- Source content: `src/data/courses.json` and `src/data/policies.json`.
- Website content and links can be edited in `src/app/` and `src/lib/data.ts`.
- Environment key generated by `setup.ps1`: `NIBT_DATA_KEY` in `.env.local`, which **must not** be shared or committed. Keep secure backups of both key and data.
- Optional LMS configuration: `NEXT_PUBLIC_LMS_URL=https://your-verified-lms.example` in `.env.local`.

## Before a public launch
This is an **application-stage preview**, not a certification of full regulatory compliance or a production-ready student information system. The site is intentionally `noindex` until `NEXT_PUBLIC_SITE_READY=true` is set following formal approvals and completion of disclosures. Read `REGULATORY_GAPS.md` before launching it publicly.

Before collecting public expressions of interest, NIBT must approve a privacy notice, storage/retention procedures and security controls. The local encrypted file storage is a demonstration solution only: it does not provide user identity management, enterprise audit logs, backups, disaster recovery or reliable storage on serverless deployments. A production deployment requires an institution-controlled database and adequate hosting/security arrangements.

The site is not an LMS or student record system. NIBT must procure/configure these independently and demonstrate Standard 7.3.3 controls as applicable.
